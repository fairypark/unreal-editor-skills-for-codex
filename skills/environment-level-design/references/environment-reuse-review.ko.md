## 소스와 장면 검증

기존 소스 검사와 대표 구간 검증 안에서 형태, 표면, 장면 조합을 나누어 판단한다. 최종 크기·시야에서 실루엣·뒷면·접지·실제 외곽을 검사하고, 저장 과정에서 노멀이 재계산되지 않았는지도 확인한다. 절벽용 열린 스캔과 독립된 바위 덩어리는 역할이 다르다. 특정 양면 노멀 수정이나 자체 메시 제작을 모든 잔디의 의무 절차로 만들지 않는다.

소수의 기존 위치에서 시험하고 승인된 다른 요소와 조명을 유지한다. 재질만 변경했다면 유효한 형태 증거는 재사용하고 표면과 관련 장면만 재검사한다. 메시·크기·피벗·WPO가 바뀌면 외곽과 제외 영역을 다시 계산한다. 36개 시험 배치, 배합 비율, 특정 색과 투과광 수치는 사례 값이다. 소스 통과는 전체 배치·바람·성능·새 맵 승인이 아니다.

## 바닥과 식생 연결

좌표계·단위·원점·시드 또는 고정 데이터·범위·분포 버전·수동 강조점을 공유한다. 식생 확률과 재질 혼합은 서로 다른 반응 곡선을 사용할 수 있다. 경로·물·바위·플레이 영역의 제외 규칙을 우선하고 최종 메시의 회전·크기를 반영한 간격을 확인한다.

CPU와 GPU에서 식이 같다는 사실만으로 결과가 같다고 판단하지 않는다. 실제 소비자가 내놓은 값을 같은 위치에서 측정하고 사전 허용 오차로 비교한다. CPU 함수를 두 번 실행한 값을 GPU 검증이라고 부르지 않는다. `validate_spatial_field_samples.py`의 `PASS_PARITY_ONLY`는 제공한 샘플만 검증하며 GPU 증거의 진위나 전체 필드·시각 품질을 승인하지 않는다.

샘플 JSON은 버전 1, 필드 ID·리비전·좌표계·단위를 담은 `authority`, 0–1의 허용 오차, 고유 ID·XYZ 위치·0–1 값을 가진 기준 샘플, 동일 ID/위치/권한을 사용하는 소비자 샘플을 요구한다. 채취 방법과 샘플 범위의 이유는 프로젝트 증거에 기록한다. 풀 전용 색 보정은 의도에 따라 풀 레이어에 적용한 뒤 흙과 혼합하고, 순수 레이어와 전이부를 확인한다.

## 라이브러리 보관

기존 소스를 덮어쓰거나 이동하지 않고 별도 버전 폴더로 복제한다. 자체 제작, 프로젝트 외부 에셋에 의존하는 프리셋, 맵 좌표가 포함된 예제를 구분한다. 잔디 메시·재질처럼 서로 연결된 자체 제작 소스는 라이브러리 내부로 참조를 다시 연결한다. 새 폴더만 저장하고 원본 파일과 기존 맵 참조를 확인한다.

목록에는 원본/복제 경로, 의존성, 파일 해시, 원본 승인 범위, 복제 검증, 교체할 입력, 미검증 항목을 남긴다. 다음 작업이 찾을 수 있도록 컬렉션 인덱스에 등록한다. 원본 승인과 복제 기술 검증은 새 맵 시각 승인·배포 권리·clean-project migration·cook·성능 승인과 다르다.

## 캡처 대안

네이티브 캡처 실패를 보존하고, 프로젝트 규칙이 허용하며 지정 검수자가 증거 종류를 인정할 때만 대체 경로를 쓴다. 규칙이 요구하는 네이티브 보증을 제공할 수 없다면 해당 게이트는 대기 상태다. 동일한 영구 카메라와 PIE 대응 카메라의 안정 ID 및 실제 Camera Manager 상태를 비교한다.

일반 엔진 캡처를 순차 실행하고, 최소 3개 원본 PNG에 요청/완료 시간, 프레임/월드 시간, 크기, 파일 시간, 해시, 전후 카메라·렌더 상태를 남긴다. 전송 전에 다시 검사한다. 과거의 3초·30틱, 4×4 RGB 평균 차이 0.5는 정적 장면 사례이지 보편적 기준이 아니다. 움직이는 물·바람·파티클에는 별도 계약이 필요하며 통과를 위해 의도된 움직임을 멈추면 안 된다.

대체 이미지에는 `native_receipt: false`, `verification_method: external_recompute`를 표시한다. 다른 카메라의 정상 진단 영수증은 대체 이미지를 인증하지 않는다. 이미지·검증·정리 결과를 분리하고, PIE 종료 실패를 이미지 검증 성공으로 감추지 않는다. 시각 승인은 별도 독립 검수자가 담당한다.

## 백엔드 변경

배치 백엔드 오류와 아트 실패를 분리한다. 오류·부분 상태를 보존하고 대안의 추가/재읽기/정리 시험 뒤 소스·시드·트랜스폼·제외 영역·충돌 의도를 유지한다. 저장과 장면 회귀를 확인한다. 한 번의 UE 빌드 오류로 HISM이나 PCG를 전역 기본값으로 지정하지 않는다.
