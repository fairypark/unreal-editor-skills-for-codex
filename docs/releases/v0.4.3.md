# v0.4.3 — Requirements dialogue before environment execution

환경 작업을 시작하기 전에 제작자의 의도를 이해하고, 중요한 미정 사항에 질문과 추천 방향을 제시하도록 실행 Skill을 보강했습니다.

## 변경 내용

- `environment-level-design`에 요구사항 대화 참조를 연결하고 영문 지침과 한국어 검토본을 추가했습니다.
- 승인된 브리프와 이전 답변을 재사용하고, 에이전트가 읽기 전용으로 확인할 수 있는 사실은 직접 확인하도록 했습니다.
- 열린 방향에는 화면·플레이 결과, 추천 이유, 장단점과 불확실성을 설명합니다. 질문 예시에는 숲의 정서, 랜드마크 노출, 자연스러움의 결함, 에셋과 실루엣, 완료 범위, 명확한 국소 수정이 포함됩니다.
- 답을 기존 설계·번역·준비도·수정 계약에 반영한 뒤 도구와 파라미터를 선택합니다. 무응답은 승인으로 간주하지 않으며, 명확한 작은 수정에서는 전체 콘셉트 설문을 다시 시작하지 않습니다.
- Handbook이 있으면 해당 원칙을 따르고, 없으면 기존 최소 계약에 적용합니다. 별도의 설계 게이트를 추가하지 않습니다.
- 공개된 v0.4.2를 계승하고 `main`에 통합합니다. 이번 추가 변경은 요구사항 대화 지침과 릴리즈 메타데이터입니다.

## 검증과 적용 범위

- 공개 v0.4.2 기반 실행 플러그인 회귀 검사 52개 통과.
- 공식 Plugin validator 및 변경한 Skill의 공식 Skill validator 통과.
- 로컬 문서 링크·앵커, `git diff --check`, 구성된 비밀정보 검사 통과.
- Plugin validator는 Codex에서 해당 도구가 제거되기 직전의 [공식 리비전 985cf47](https://github.com/openai/codex/tree/985cf47a4eb6084b2ff6b30ebdb1216acda85bb4/codex-rs/skills/src/assets/samples/plugin-creator)을 사용했습니다.

검증 범위는 지침과 패키지 구조 및 기존 회귀 검사입니다. 새 질문 흐름의 실사용 효과와 라이브 Unreal Editor 실행은 이번 릴리즈 검증에 포함하지 않았습니다. MCP, Hook, 사용량 수집 및 동의 정책은 이번 요구사항 대화 보강으로 변경되지 않습니다.
