# Unreal Editor Skills for Codex v0.2.0

This release adds transparent, consent-based local usage metrics for evaluating whether the
plugin's Unreal workflows are reliable and useful.

## Highlights

- Asks once in an Unreal project before collecting anything.
- Keeps metrics local to the user's device with no upload or remote transmission.
- Never stores prompts, assistant messages, paths, project names, Actor or Asset names,
  tool arguments, tool response contents, or raw session identifiers.
- Measures eligible sessions, Unreal MCP outcomes, retries, mutation verification, durations,
  and optional 1-5 ratings.
- Adds natural-language controls to enable, disable, inspect, summarize, rate, and delete data.
- Keeps metrics implementation separate from Epic-derived Unreal workflow Skills to reduce
  future upstream synchronization conflicts.
- Adds English and Korean introduction copy for plugin listings and release pages.

## Validation

- Official Plugin validator passed.
- All four Skills passed the official Skill validator.
- Seven consent, privacy, failure-classification, summary, feedback, and deletion regression
  tests passed against both the source tree and the installed personal plugin.
- The personal plugin was reinstalled with a fresh Codex cachebuster.
- A new read-only Codex run successfully completed `list_toolsets`, `describe_toolset`, and
  `get_current_level` against Unreal Engine 5.8 without mutating Editor state.
