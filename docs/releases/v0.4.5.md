# v0.4.5 — Environment source checks and reusable ground cover

초지 제작 결과를 바탕으로 환경 소스 진단, 바닥과 식생의 연결, 재사용 라이브러리 보관과 조건부 캡처 절차를 보강했습니다. 사용자가 요청한 Codex 확장이며 Epic upstream 변경으로 표기하지 않습니다.

## 변경 내용

- 형태·표면·장면 검사를 기존 소스/대표 구간 게이트에 연결합니다. 재질만 수정하면 유효한 형태 증거를 재사용하고, 메시·크기·피벗·WPO 변경은 최종 외곽과 제외 영역을 재검증합니다.
- 공유 공간 필드의 버전·좌표·단위·소비자 매핑과 실제 샘플 비교를 정의하고 레이어별 색 보정, 저장된 노멀 및 제한된 배치 백엔드 복구 절차를 추가했습니다.
- `validate_spatial_field_samples.py`가 기록된 스칼라 샘플을 읽기 전용으로 비교합니다. 중복 JSON 키, 중복/누락 ID, 좌표·버전 불일치, 비유한값과 범위 오류는 거부합니다. `PASS_PARITY_ONLY`는 제공한 샘플의 수치 일치만 의미합니다.
- 의존성 없는 초지 시스템 계약과 소스 검사 템플릿을 추가해 설치 가능한 템플릿을 5개로 확장했습니다. 기존 파일 덮어쓰기 거부 정책을 유지합니다.
- 네이티브 복제와 참조 재연결, 원본 보존, 의존성·승인 범위·복제 검증 기록 및 컬렉션 인덱스 운영을 설명합니다.
- 캡처 대안은 프로젝트 계약과 지정 검수자가 허용한 경우만 사용합니다. 별도 진단 영수증으로 이미지를 인증하지 않으며, 필요한 네이티브 보증을 제공할 수 없으면 게이트는 대기합니다.
- 대응 한국어 검토본을 제공하고 Handbook v0.2.16의 개념적 판단과 실행 지침을 구분합니다.

## 검증과 적용 범위

- 회귀 검사 63개 통과. 샘플 비교기 11개와 기존 템플릿·사용량 수집 개인정보/동의 검사를 포함합니다.
- 공식 Plugin validator와 6개 Skill의 공식 Skill validator 통과.
- 변경 문서의 로컬 링크·앵커, JSON 파싱, `git diff --check`, 구성된 비밀정보 검사 통과.
- 독립 검토의 중복 JSON 키 발견을 수정하고 CLI 회귀 검사로 재확인했습니다.
- Plugin validator와 개인 설치용 cachebuster는 [공식 OpenAI 리비전 985cf47](https://github.com/openai/codex/tree/985cf47a4eb6084b2ff6b30ebdb1216acda85bb4/codex-rs/skills/src/assets/samples/plugin-creator)을 사용했습니다.

Epic upstream 기준 리비전은 `a6aa73ada02a9fb1f5415bec491f9942c519b297`로 유지합니다. MCP 연결, Hook, 선택적 사용량 수집의 동의·수집 범위는 변경하지 않았습니다.

공개 패키지에는 Unreal 에셋과 제3자 텍스처를 포함하지 않습니다. 도구는 GPU 샘플의 진위, 전체 필드, 시각 품질 또는 cook·성능·clean-project migration을 승인하지 않습니다. 캡처 문서는 모든 Engine 빌드의 대체 캡처 경로를 실행 검증했다는 의미가 아닙니다.
