# v0.4.4 — MCP proxy recovery and concurrency guidance

Epic upstream의 MCP 프록시 설치·복구 안내와 동시 호출 설명을 Codex에 맞춰 반영했습니다. 공개 v0.4.3의 요구사항 대화 흐름을 유지합니다.

## 변경 내용

- 선택적 Engine 프록시의 플랫폼별 실행 파일, 설치·제거, MCP JSON에서 Codex TOML로 옮기는 절차를 추가했습니다. 기본 연결은 직접 HTTP이며, 프록시를 선택하면 기존 직접 연결을 비활성화해 하나의 Unreal 연결만 사용합니다.
- 프록시 상태와 캐시된 도구 목록을 실제 Editor 접근 성공과 구분합니다. 도구 목록 변경 알림, 오래된 클라이언트 목록, STDIO 연결 종료의 복구 절차를 설명하고, 수정 작업 전에 `list_toolsets`와 읽기 전용 Unreal 호출의 성공을 요구합니다.
- 기존 HTTP preflight가 STDIO 프록시의 준비 상태를 검증하지 않는다는 범위를 명시합니다. 프록시에서는 기록된 upstream endpoint, Editor listener와 실제 읽기 전용 호출을 확인합니다.
- MCP가 동시 요청을 동기화하고 비동기 도구가 겹칠 수 있다는 upstream 설명을 반영했습니다. 의존 호출과 같은 상태를 수정하는 작업은 순차 실행하며, 프로젝트의 game-thread 순차 호출 규칙을 유지합니다. 독립 작업의 동시 실행은 도구 지원과 프로젝트 지침이 허용할 때만 가능합니다.
- Skill, 복구 참조, README와 SessionStart 컨텍스트의 설명을 맞췄습니다. 사용량 수집, 동의 정책과 Hook 등록은 유지합니다.
- `THIRD_PARTY_NOTICES.md`의 upstream 리비전을 `a6aa73ada02a9fb1f5415bec491f9942c519b297`로 갱신했습니다.

## 검증과 적용 범위

- 기존 실행 플러그인 회귀 검사 52개 통과. 사용량 수집의 개인정보·동의 회귀 검사를 포함합니다.
- 공식 Plugin validator와 6개 Skill의 공식 Skill validator 통과.
- SessionStart hook의 일반 폴더 무출력, 하위 디렉터리의 Unreal 프로젝트 탐지, 프로젝트 설정 유무와 Engine 소스 탐지 확인.
- 변경 문서의 로컬 링크·앵커 11개와 Codex TOML 예제 파싱 확인.
- `git diff --check` 및 구성된 비밀정보 검사 통과.
- Plugin validator와 개인 설치용 cachebuster 도구는 기존 릴리스와 같은 [공식 OpenAI 리비전 985cf47](https://github.com/openai/codex/tree/985cf47a4eb6084b2ff6b30ebdb1216acda85bb4/codex-rs/skills/src/assets/samples/plugin-creator)을 사용했습니다.

이번 검증은 지침, 패키지 구조, Hook과 기존 회귀 검사 범위입니다. Engine 프록시 바이너리를 설치하거나 라이브 Editor 중단·복구 및 병렬 도구 실행을 시험하지 않았습니다. 프록시 선택 시 해당 Engine 빌드와 Codex 호스트에서 별도 확인해야 합니다.
