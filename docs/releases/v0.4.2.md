# v0.4.2 — Strategy-aware environment and PCG execution

This release strengthens live Unreal environment execution with explicit dependent-strata strategy selection and the current grounding, MCP, evidence, and production-safety updates.

## Highlights

- Requires a `Dependent-Strata Strategy Gate` before rock/hardscape and grass/ground-cover generation or batch placement.
- Carries the selected distance-exclusion, alternate-mask, authored, or pending strategy into execution fallback guidance.
- Keeps the hardscape output or conservative footprint as the sole exclusion authority when the video-style method is selected, and verifies final bounds gaps rather than center-point distance.
- Includes the current four-corner building-grounding routing, live MCP preflight/recovery safeguards, persistent evidence checks, and related environment execution updates present in this release branch.
