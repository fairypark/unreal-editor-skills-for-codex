# v0.3.0 release notes candidate

## Added

- `environment-level-design` skill with an explicit Visual Gate-first priority:
  art-direction fidelity and 360-degree completeness precede performance and
  gameplay polish.
- PCG biome orchestration guidance based on the referenced forest, river, and
  path benchmark: boundary, density field, exclusions, layer subgraphs, and
  output/audit.
- Independent canopy-through-geology strata, coordinated river/path masks,
  edge-to-core density, blue-noise/cluster distribution, visual diagnostics,
  and no-visual-regression performance policy.
- Landscape, streaming proxy, ground snapping, placement-preserving collision,
  and UI-observer cleanup workflows.
- A client-neutral external runtime handoff covering Landscape, PCG, capture,
  Fab feasibility, packaging, and live validation requirements.
- Automated tests for priority order, evidence gates, benchmark structure,
  capability-gap routing, reusable-content hygiene, and absence of bundled
  Unreal runtime source.

## Changed

- `unreal-mcp` no longer assumes a third-party Landscape toolset is installed.
- `create-toolset` routes runtime implementation gaps to the separately assigned
  Unreal extension project.
- Plugin prompts now include a Visual Gate-first environment workflow.

## Removed

- In-repository Unreal Editor runtime plugin source, packaging scripts, and
  release workflow. This Codex plugin owns skills and orchestration only.

## Verification

- Repository unit tests: 24 passed.
- Official Skill validation: `environment-level-design`, `create-toolset`, and
  `unreal-mcp` passed.
- Official Codex Plugin validation passed.
- GitHub Actions YAML parsed successfully.

## Known limitations

- No live Unreal mutation was performed for this skills-only change.
- Landscape batch reimport, proxy rebuild, diagnostic snap, PCG weighted-entry
  CRUD/audit, LandscapeGrassType editing, and PIE-safe capture remain external
  runtime capability gaps.
- The main checkout contains uncommitted versions of
  `skills/environment-level-design` and requires a deliberate file-level merge.
