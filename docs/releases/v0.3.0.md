# Unreal Editor Skills for Codex v0.3.0

This release adds a reusable environment-level design workflow with optional project onboarding,
golden-slice quality gates, and independent visual supervision.

## Highlights

- Adds the `environment-level-design` Skill for production-quality Unreal environment work.
- Separates the builder from a read-only visual supervisor when agent delegation is available.
- Preserves fixed-camera evidence, failed audits, target-level verdicts, and full-level acceptance
  as distinct decisions.
- Introduces optional `off`, `recommended`, and `strict` project adoption modes.
- Provides minimal project-policy, Visual Recipe, and visual-audit templates.
- Adds a sanitized CodexMiniArena procedural case study that demonstrates the decision loop without
  distributing project paths, asset identifiers, Actor transforms, proprietary references, or
  project-specific thresholds.
- Keeps explicit user instructions, `AGENTS.md`, registered project skills, and project-owned policy
  authoritative over plugin guidance and templates.
- States clearly that read-only supervision is instruction-level unless the runtime provides a
  technically restricted tool surface.

## Onboarding behavior

When no project-owned visual policy exists, Codex may introduce the workflow and offer minimal,
sample-informed, custom, or skipped setup. It does not silently overwrite `AGENTS.md` or treat the
CodexMiniArena case study as a preset.

Project-specific categories, thresholds, camera roles, hard failures, performance targets, and art
direction remain in project-owned files.
