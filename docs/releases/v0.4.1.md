# v0.4.1 — Mandatory Handbook gate for first level-work activation

This patch release makes the Handbook boundary explicit before new or materially changed level work enters live Editor execution.

## Highlights

- Announces on the first level-work Skill activation that applicable Unreal Development Handbook Skills and chapter guidance are mandatory when the Handbook is available.
- Routes broad level creation, rebuild, dressing, and environment changes through `environment-level-design` before low-level `unreal-mcp` execution.
- Preserves the standalone fallback contract when the Handbook is not installed.
- Adds regression coverage for the first-activation notice and execution routing.

## Compatibility

The Handbook remains optional. Existing narrow, isolated Editor operations continue to use `unreal-mcp` directly, while new or materially changed level work establishes the Handbook gate before mutation.
