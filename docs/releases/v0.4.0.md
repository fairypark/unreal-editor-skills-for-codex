# v0.4.0 — Handbook split and execution-layer release

This release makes the boundary between durable Unreal development reasoning and live Editor execution explicit.

## Highlights

- The Fairypark marketplace now catalogs **Unreal Development Handbook for Codex** alongside this plugin.
- `environment-level-design` consumes the Handbook's world-design and production-validation Skills when available, while retaining a compact fallback contract for standalone use.
- Environment guidance now focuses on live Landscape, PCG, Foliage, material, collision, save, PIE, persistent-camera evidence, and production-template operations.
- General level-design philosophy, reusable-content theory, quality-gate theory, and the bundled case study were removed from the execution plugin after being distilled into the Handbook.
- Persistent evidence receipts, external hash trust anchors, handoff-time verification, neutral supervisor packets, and optional extension-usefulness metrics remain in the execution layer.
- The MCP endpoint preflight reports actionable transport and initialization failures before live tool calls.

## Compatibility

The Handbook is optional. Existing Editor-only workflows continue to operate and use a minimal task contract when Handbook Skills are unavailable. Restart the desktop app and begin a new task after installing or updating either plugin.
